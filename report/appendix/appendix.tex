\chapter{Installation, Execution and Reproduction}
\label{app:reproduce}

\section*{Running the system locally}
\begin{enumerate}
  \item Install Node.js (version 20 or newer) and make a MongoDB database available, either locally or hosted.
  \item Install the project dependencies with npm from the repository root. This installs both the backend and the frontend packages.
  \item Create the backend configuration file from the example file supplied in \code{backend}, and set at least the database address. For e-mail, also set the SMTP account details. Without them, development mode prints e-mails, including verification codes, to the server console.
  \item Run the backend's seed script once to create the first administrator and delivery agent. In production, their passwords must be supplied through environment variables.
  \item Start both parts with the development script in the repository root. The API listens on port 5000, and the web client on port 5173 forwards \code{/api} requests to it.
\end{enumerate}

\section*{Reproducing the evaluation}
The evaluation tools are stored in \code{report/evidence}. The exact commands are listed in \code{report/README.md}. The procedure is:
\begin{enumerate}
  \item Install the test-only tools (an in-memory MongoDB, a Socket.IO client and a headless-browser driver) in a separate folder, so the project's own dependencies remain unchanged. The first run downloads a MongoDB binary of about 600\,MB.
  \item Run the black-box test harness against the backend. It writes the results file and a redacted server log.
  \item Regenerate the result tables used in Chapter~5 and Appendix~\ref{app:tests} from the results file.
  \item Optionally, run the screenshot script, which requires Google Chrome, to capture the running system.
  \item Run the frontend linter and the production dependency audit for the static checks.
\end{enumerate}
The harness never reads \code{backend/.env}. It removes SMTP and database variables from its environment and uses a temporary database, so it cannot touch production data or send e-mail.

\section*{Environment variables}
Variable \emph{names} used by the backend (values are deployment secrets and are not reproduced here): \code{PORT}, \code{NODE_ENV}, \code{TRUST_PROXY_HOPS}, \code{MONGODB_URI}, \code{JWT_SECRET}, \code{JWT_ACCESS_EXPIRES}, \code{BCRYPT_ROUNDS}, \code{COOKIE_SAMESITE}, \code{COOKIE_SECURE}, \code{EMAIL_VERIFICATION}, \code{CLIENT_ORIGIN}, \code{SOCKET_CORS_ORIGIN}, \code{APP_URL}, \code{MAIL_HOST}, \code{MAIL_PORT}, \code{MAIL_SECURE}, \code{MAIL_USER}, \code{MAIL_PASS}, \code{MAIL_FROM}, \code{MAIL_FROM_NAME}, \code{GEOCODE_CONTACT}, \code{SEED_ADMIN_EMAIL}, \code{SEED_ADMIN_PASSWORD}, \code{SEED_AGENT_EMAIL}, \code{SEED_AGENT_PASSWORD}.
